## What the user wants the code to be like

- Modular: each `plugin/<name>/init.lua` installs its own plugin and its own
  dependencies. Do **not** centralise plugin specs into one manifest.
- Keymaps stay near the thing they belong to. Do **not** centralise all keymaps.
- Prefer readable, idiomatic, simple Lua over clever abstractions.
- Keymap style: `<LEADER>` (uppercase), `:cmd<CR>` (not `<CMD>cmd<CR>`), and
  `desc` metadata.
- Keep the config performant without lazy-loading everything. `vim.pack` loads
  plugins eagerly by design; the concern is blocking work on startup, keystrokes,
  and redraws.
- Treesitter highlighting is preferred over LSP semantic highlighting.
- The 80-column marker should only appear where a line actually reaches column
  80, not as a full-height `colorcolumn`.
- Keep `minimal-init.lua` as an emergency fallback.
- Keep `plugin/_template/` for copy-paste, but use `.lua.template` extensions so
  Neovim does not source them.
- `exrc` should stay enabled; Neovim only loads trusted project configs.
- Use small, focused commits. Do not commit unrelated dotfiles changes.

## Useful traps and facts

- Hyprland 0.56 with Lua config no longer accepts legacy
  `hyprctl dispatch resizewindowpixel` / `centerwindow` for the scratch window.
  The working implementation uses `hyprctl eval` with
  `hl.dsp.window.resize` / `hl.dsp.window.center`.
- `lua/settings/colorcolumn.lua` adds a window-local `matchadd` for `\%80v` to
  every normal window. It intentionally does not use `'colorcolumn'`.
- `vim.lsp.semantic_tokens.enable(false)` is intentional.
- `lua/ui/theme.lua` is the theme registry; plugin themes register functions and
  are applied on `ColorScheme` and once on `VimEnter`.
- Telescope theme ordering currently overwrites Kanagawa/Tokyo Night Telescope
  overrides. This is the most important known design bug in the current config.
- `lua/h.lua` `mod_hl` loses attributes on linked groups because `link` wins.
  This affects GitSigns/MiniDiffSign background tweaks.
- Generated color files must not be edited by hand.
